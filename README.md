# DK Arrow Ez Drawing Tool

배경 이미지를 참고로 띄워 놓고 여러 번 꺾이는 화살표를 빠르게 그린 뒤, 화살표만 투명 PNG로 저장하거나 배경과 함께 합성하여 저장할 수 있는 Windows용 도구입니다.

## 주요 기능

- PNG/JPG/JPEG/BMP/GIF 배경 이미지 열기
- 이미지 파일 드래그 앤 드롭으로 바로 열기
- 여러 점으로 구성된 꺾이는 화살표 그리기
- `Shift`를 누른 상태에서 수평/수직 직각 스냅
- 화살표별 이름, 색상(`#RRGGBB`), 선 두께 변경
- 자주 쓰는 색상 템플릿 버튼으로 빠른 색상 지정
- 새 화살표는 직전에 새로 만든 화살표의 색상/두께를 이어받으며 프로그램 재실행 후에도 유지
- Ctrl/Shift로 여러 화살표를 선택해 색상·두께 일괄 변경 및 삭제
- 화살표 경로 점 드래그 수정
- 선택한 화살표 또는 경로 점을 방향키로 1px 이동
- `Shift + 방향키`로 10px 이동
- 마우스 휠 줌, 가운데 버튼 드래그 팬
- 작업 영역 더블클릭으로 화면 맞춤 초기화
- `.arrowproj` 파일에 배경 이미지와 작업 내용을 함께 저장/복원
- 투명 배경 PNG 출력
- 배경 이미지를 포함한 PNG 출력 옵션
- PNG 파일 접미어 직접 지정 및 재실행 후 유지

## 다운로드 및 실행

GitHub의 **Releases**에서 최신 Windows x64 ZIP 파일을 내려받아 원하는 폴더에 압축을 풀고 `DK Arrow Ez Drawing Tool.exe`를 실행하면 됩니다.

배포본은 self-contained 방식으로 빌드되므로 별도의 .NET 설치 없이 실행할 수 있도록 구성되어 있습니다.

## 기본 사용법

1. **배경 이미지 열기**를 누르거나 이미지 파일을 프로그램 창으로 드래그합니다.
2. **새 화살표**를 누릅니다.
3. 이미지 위를 왼쪽 클릭하여 경로 점을 추가합니다.
4. 필요하면 `Shift`를 누른 채 클릭하여 수평/수직 선으로 맞춥니다.
5. 오른쪽 클릭 또는 `Enter`로 화살표를 완성합니다.
6. 우측 목록에서 화살표를 선택해 이름, 색상, 선 두께를 바꿉니다.
7. **PNG 출력**을 눌러 결과를 저장합니다.

## 조작 방법

| 기능 | 조작 |
| --- | --- |
| 점 추가 | 왼쪽 클릭 |
| 수평/수직 고정 | `Shift + 왼쪽 클릭` |
| 화살표 완성 | 오른쪽 클릭 또는 `Enter` |
| 작성 취소 | `Esc` |
| 확대/축소 | 마우스 휠 |
| 화면 이동 | 가운데 버튼 드래그 |
| 화면 맞춤 초기화 | 작업 영역 더블클릭 |
| 여러 화살표 선택 | `Ctrl` 또는 `Shift` + 목록 선택 |
| 선택 항목 1px 이동 | 방향키 |
| 선택 항목 10px 이동 | `Shift + 방향키` |
| 도움말 | 상단 `?` 버튼 |

## 작업 저장

**작업 저장**을 사용하면 배경 이미지와 화살표 정보가 하나의 `.arrowproj` 파일에 저장됩니다. 원본 배경 이미지가 다른 위치로 이동하거나 삭제되어도 저장된 작업 파일만으로 다시 열 수 있습니다.

기본 파일명은 현재 배경 이미지 이름을 따라갑니다.

예: `map.png` → `map.arrowproj`

## PNG 출력

### PNG 파일 접미어

상단 접미어 입력칸의 기본값은 `_arrows`입니다. 예를 들어 배경 이미지가 `map.png`이면 기본 출력명은 `map_arrows.png`이며, `배경 포함`을 켜면 `map_arrows_bg.png`가 됩니다. 접미어를 변경하면 이후 PNG 출력에 사용되고 프로그램을 다시 실행해도 유지됩니다.

기본 출력은 배경이 투명한 PNG입니다.

- `배경 포함` 꺼짐: `map_arrows.png`
- `배경 포함` 켜짐: `map_arrows_bg.png`

출력 해상도는 배경 이미지 원본 크기를 기준으로 합니다.

## 소스에서 빌드

필요 환경:

- Windows 10/11
- .NET 8 SDK

```powershell
dotnet build -c Release
dotnet run -c Release --no-build
```
